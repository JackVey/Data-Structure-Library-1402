# جلسه هشتم!
توی این جلسه باید کد ساختمان داده Treap رو پیاده کنید. شبیه BST هست با چند تفاوت. مثل جلسه قبل یسری داده ایجاد میکنید و داخل Treap و BST درج میکنید، با دو تفاوت:
1. لازم نیست جستجوی ناموفق داشته باشید.
2. دو تا پایگاه داده خواهید داشت، یکی به صورت رندوم تولید شده و دیگیری همون اولی هست ولی نیمه سورت شده است، یعنی اینکه در ابتدا بر اساس کلید سورت شده ولی توی یسری بازه‌ی تصادفی برعکس شده.


> [!NOTE]
> فقط مدت زمانی که کد داره insert و search میکنه رو اندازه بگیرید!
> ساختمان داده BST برای پایگاه داده نیمه سورت شده، یه زمان وحشتناکی برای درج داده‌ها بهتون میده. برای تعداد داده‌های زیاد، لازم نیست زمان بگیرید.
