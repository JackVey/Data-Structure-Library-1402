# جلسه پنجم!
توی این جلسه باید کد ساختمان داده Chain table رو با استفاده از Doubly linked list پیاده سازی کنید. این جلسه با یک جلسه ادغام شده و به همین دلیل هستش که سر و کله‌ی Doubly linked list اینجا پیدا شده! بعد از این کار، برای بنچمارک، باید m داده رو که متشکل هستند از شملره تلفن و اسم رو در این ساختمان داده insert کنید و زمان اون رو اندازه بگیرید. همچنین باید دو زمان جستجو بین داده ها رو هم اندازه‌گیری کنید؛ لیست یکی از جستجو ها، متشکل از سطرهای تصادفی از پایگاه داده اصلی با m داده هستش(یک دهم m سطر) و لیست دیگر شامل یک دهم m سطر از داده های رندوم هست که توی پایگاه داده وجود نداره و لیست جستجوی ناموفق هستش. 


> [!NOTE]
> فقط مدت زمانی که کد داره insert و search میکنه رو اندازه بگیرید!
