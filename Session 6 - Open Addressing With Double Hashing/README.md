# جلسه ششم!
توی این جلسه باید کد ساختمان داده Chain table رو که مشکل کالیژن با Double hash رفع شده رو پیاده کنید. به ازای سه تا m که عدد اول هستند و از عدد n (تعداد داده ها) کمی بیشترن، کد رو بنچمارک میکنید و زمان درج، جستجوی موفق و ناموفق رو اندازه میگیرید و گزارش میکنید!
