# جلسه نهم!
توی این جلسه باید کد ساختمان داده Interval tree رو پیاده کنید، که عملا همون BST یا Treap هستش ولی باید با بازه ها کار کنه. شما نمره‌ی کامل رو برای پیاده سازی Interval tree بر روی Treap و نمره‎‌ی ناقص رو برای پیاده سازیش روی BST کسب خواهید کرد. بعد از پیاده سازی، سه تا پایگاه داده میسازید(تفاوت این 3 تا، این هست که تعداد overlap ها یکی بیشتر از اون یکی هست) و زمان درج رو اندازه میگیرید و گزارش میدید. برای قسمت دوم(این قسمت سال به سال متفاوت بوده) باید تعداد overlap ها رو برای هر داده بشمارید. برای هر پایگاه داده، کمترین، بیشترین، میانگین و کل تعداد overlap ها رو گزارش میکنید. همچنین میزان زمانی که طول کشید که کد تعداد overlap های هر داده در هر دیتا بیس رو پیدا کنه هم گزارش میکنید.


> [!NOTE]
> فقط مدت زمانی که کد داره insert و search میکنه رو اندازه بگیرید!
> توی زبان پایتون برای n های بزرگتر از 100 هزار، میزان زمان زیادی برای پیدا کردن تعداد overlap ها خرج میشه. مثلا برای 200 هزار داده، از 780 ثانیه تا 910 ثانیه متغیر بوده! سعی کنید n کوچکی رو انتخاب کنید.
